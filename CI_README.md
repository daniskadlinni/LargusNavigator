# Автоматическая проверка Largus Navigator

GitHub Actions выполняет два уровня проверки.

1. На каждом push/PR: генерация Xcode-проекта, сборка и unit tests.
2. Вручную (Actions -> Largus Navigator CI -> Run workflow) и раз в сутки: реальные сетевые проверки трех контрольных маршрутов Москва (Байкальская 17к1) -> Замьяны:
   - через Воронеж и Анну;
   - через Тамбов;
   - через Воронеж, Анну и Ахтубинск.

Live-тест проверяет, что маршрут действительно построен, длина выглядит реалистично, геометрия не пустая и OSMFuelService возвращает не подозрительно малое число крупных АЗС. Если Overpass отдает случайный неполный результат или сервис ломается, workflow должен стать красным, а не выдавать пользователю такую сборку как проверенную.
